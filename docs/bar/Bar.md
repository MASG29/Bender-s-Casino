# Bar — adiado

**Não é um jogo.** É uma zona de convívio: beber, conversar, ambiente. Fica para depois dos
quatro jogos e do login.

Ainda sem dono e sem tarefas fechadas. Duas notas para quando chegar a vez:

- Se as bebidas custarem fichas, o Bar precisa de back-end (débito no saldo) e passa a ser uma
  espécie de "loja". Se for só decoração e ambiente, é 100% front-end.
- É o sítio natural para pôr o `JokeService` que já existe.

## Quando chegar a vez

Tarefas já esboçadas, guardadas aqui em vez de andarem no meio dos jogos:

| # | Tarefa | Detalhe |
|---|--------|---------|
| Bar-B1 | Consumos | Só é preciso se as bebidas custarem fichas: débito no saldo do jogador e lista de bebidas com preço. |
| Bar-F1 | Vista do bar | Balcão, ambiente, sítio para estar entre jogos. |
| Bar-F2 | Menu de bebidas | Lista com preços; desativar o que não se pode pagar. |
| Bar-F3 | Servir a bebida | Animação/feedback ao pedir. |
| Bar-F4 | Ambiente | Música, luz, NPCs de fundo. |
| Bar-F5 | Assets | Balcão, copos, garrafas. |
